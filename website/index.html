02  /  What it does

Everything between ⌥⇧4 and send.

01

Capture anything

Drag an area, click a window, grab the whole screen, or open All-In-One for every mode in one toolbar. A magnifier, window snapping and a frozen-screen mode make pixel-exact selections easy.

  • Area
  • Window
  • Fullscreen
  • Previous area
  • Self-timer
  • All-In-One
02

Mark it up in seconds

Arrows, shapes, text, numbered steps, highlighter, blur and pixelate, spotlight — then drop the shot on a clean background with padding and shadow. Everything stays editable.

  • 14 tools
  • Backgrounds
  • Undo history
  • .superscreenshot files
03

Never hunt for a file again

Each capture waits in a small floating card. Drag it straight into Slack or Figma, copy it, annotate it, pin it above your windows, or upload it — no Save dialog in sight.

  • Drag & drop
  • Pin to screen
  • Capture history
04

Record video or GIF

Record any part of the screen with microphone, system audio, a camera bubble, click highlights and keystrokes. Trim and export in the built-in editor.

  • MP4 · GIF
  • 60 fps
  • Mic + system audio
  • Camera
05

Studio Mode for demos

Super Screenshot records where you click and move, then zooms in automatically, smooths the cursor and frames the result on a background — product demos without an editing degree.

  • Auto zoom
  • Smooth cursor
  • Timeline
  • 4K export
06

Copy text from anything

Select any part of the screen — an image, a video, a locked PDF — and the text lands on your clipboard. Recognition runs on-device, in many languages, and reads QR codes too.

  • On-device OCR
  • QR codes
  • Scrolling capture

04  /  Privacy

Your screen is yours.

Super Screenshot is a local app. Screenshots, recordings, annotations and text recognition all run on your Mac. There's no account, no analytics and no server to send anything to. Files leave only when you upload them — to a destination you set up yourself.

Nothing leaves
this Mac
  • No account or sign-in
  • No telemetry, analytics or crash reports
  • Text recognition with on-device Vision
  • Upload keys stored in your Keychain
  • MIT-licensed source — read every line

05  /  Install

Three steps. One minute.

  1. 1

    Paste this into Terminal

    It downloads the latest release, places Super Screenshot in Applications and opens it.

    curl -fsSL https://udsy19.github.io/super-screenshot/install.sh | bash
  2. 2

    Allow Screen Recording

    A short welcome guide walks you through the one permission macOS needs before any app can capture the screen.

  3. 3

    Press ⌥⇧4

    Drag over anything. Prefer macOS's ⇧⌘4? Pick it during setup — every shortcut is yours to change.

Rather use a disk image? Download the DMG, drag Super Screenshot into Applications, then on first launch open System Settings → Privacy & Security and click Open Anyway. Super Screenshot isn't notarized by Apple, so macOS asks once.

06  /  Questions

Is it really free?

Yes — MIT-licensed open source. No subscription, trial or account.

Does anything get uploaded?

Never by default. Uploading only happens after you add your own destination in Settings → Upload and choose to upload a capture.

Why does macOS ask before opening the DMG version?

Super Screenshot is an independent app without Apple notarization, so a browser-downloaded copy needs one confirmation under Privacy & Security → Open Anyway. The one-line installer doesn't.

How do I update or uninstall?

Run the install command again to update. To uninstall: curl -fsSL https://udsy19.github.io/super-screenshot/install.sh | bash -s -- --uninstall

Is this CleanShot X?

No. Super Screenshot is an independent, from-scratch project inspired by CleanShot X's workflow. It isn't affiliated with CleanShot X or MTW and shares none of their code or assets.
