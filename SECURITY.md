# Security Policy

Super Screenshot runs entirely on your Mac. It has no accounts, no analytics and no servers; the only network traffic is
uploads to a destination **you** configure (S3-compatible storage, your own HTTP endpoint or a synced folder).
Upload secrets are stored in the macOS Keychain.

## Reporting a vulnerability

Please **do not** open a public issue. Use GitHub's
[private vulnerability reporting](https://github.com/udsy19/super-screenshot/security/advisories/new) instead.
You'll get a response within a few days, and a fix will be released as soon as practical.

## Supported versions

Only the latest release receives security fixes.
